Safe Subprocess Execution Architecture

🛡️

Pure AST Parsing Without `eval()`

Zero execution danger: source payloads are strictly compiled into AST tokens via Python's standard library ast.parse() without ever invoking exec() or eval() on user logic.

🔐

Sandboxed Shell Escaping

The PHP gateway isolates payloads in temporary files with randomized hashes (`uniqid()`), escaping system command boundaries with escapeshellarg().

📊

McCabe Complexity Traversal

An ast.NodeVisitor walks the syntax tree, enumerating decision points (If, While, For, BoolOp) to calculate McCabe's standard metric $V(G) = E - N + 2P$.
